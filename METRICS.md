## Alert latency

Not yet measured in a live-lab run. Method: time from window close (ingest time of the
last event in a window) to alert record emitted; record in `logs/siem.log`. Default window
is 60s; expect sub-second scoring after window close on lab-scale traffic.

## Drift handling

Rolling mean/std per feature (stdlib path) + `scoring.update_cadence_sec` retrain cadence.
Drift evaluation procedure: retrain on a newer window of normal flows, re-run
`siem evaluate`, confirm AUC does not collapse and FP stays low.
